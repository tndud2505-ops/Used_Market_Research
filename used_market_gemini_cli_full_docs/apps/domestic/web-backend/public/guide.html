USED PICK

이용 안내

중고 PC와 컴퓨터 부품의 공개 매물을 검색하고 중고시세를 비교하는 서비스입니다. 거래는 상품 원문을 제공한 사이트에서 직접 진행됩니다.

중고 PC 검색 기능

  • CPU, 그래픽카드, RAM, 메인보드, SSD, HDD, 파워서플라이를 모델별로 찾습니다.
  • 중고 PC 부품의 현재 매물과 최근 30일 중고시세를 출처별로 비교합니다.
  • 상품별 출처와 원문 링크를 확인해 판매 상태와 상세 조건을 직접 살펴볼 수 있습니다.

이용 방법

  1. 상단 검색창에 찾는 중고 PC 부품명, 브랜드 또는 모델을 입력합니다.
  2. CPU·그래픽카드·RAM 같은 카테고리와 제조사·세대·용량 필터를 선택합니다.
  3. 결과의 출처와 등록일을 확인한 뒤, 상품 원문에서 현재 판매 상태와 거래 조건을 확인합니다.

데이터 출처와 정확도

검색 결과는 다나와 장터·중고나라·번개장터·헬로마켓·리씽크몰·eBay·쿨엔조이에서 미리 수집한 공개 PC 부품 매물을 기준으로 정리합니다. 국내 개인 중고, 리퍼비시, 해외 중고는 서로 다른 시장군으로 구분합니다. 원문이 수정되거나 삭제되면 USED PICK의 표시와 실제 상태 사이에 차이가 생길 수 있습니다.

가격, 배송비, 구성품, 판매 가능 여부는 거래 전에 반드시 원문에서 다시 확인해 주세요. USED PICK은 상품의 진품 여부, 판매자 신뢰도, 거래 성사를 보증하지 않습니다.

외부 링크와 수익화

수익화 모듈은 기본적으로 꺼져 있습니다. 운영 검토를 통과한 정확한 PC 제품 또는 부품 카테고리 목적지가 있을 때만 검색 결과 뒤에 광고 1개를 표시할 수 있으며, 일반 홈페이지나 관련 없는 상품으로 연결하지 않습니다.

제휴 링크에는 광고·수수료 가능성·시세와 추천순에 영향을 주지 않는다는 고지를 함께 표시합니다. 제휴 상품은 검색 매물이나 가격 통계 표본에 포함하지 않습니다.

상품을 선택하면 해당 상품을 제공한 외부 사이트로 이동합니다. 결제, 배송, 환불 및 회원 이용은 각 외부 사이트의 정책과 판매자 조건을 따릅니다.

브라우저에 저장되는 정보

최근 검색어, 찜한 상품, 최근 본 상품은 편의를 위해 사용자의 브라우저 저장 공간에 보관됩니다. 회원가입이나 별도 계정 없이 사용할 수 있으며, 저장된 정보는 브라우저의 사이트 데이터 삭제 기능으로 지울 수 있습니다.

USED MARKET

이용 안내

중고마켓의 공개 상품 목록을 검색하고 비교하는 서비스입니다. 거래는 상품 원문을 제공한 사이트에서 직접 진행됩니다.

서비스가 제공하는 기능

  • 상품명·브랜드·모델을 기준으로 여러 중고마켓의 공개 목록을 검색합니다.
  • 사이트와 카테고리를 선택하고 가격, 등록 시점, 추천순으로 결과를 정렬합니다.
  • 상품별 출처와 원문 링크를 표시해 판매 상태와 상세 조건을 직접 확인할 수 있게 합니다.

이용 방법

  1. 상단 검색창에 찾는 상품명, 브랜드 또는 모델을 입력합니다.
  2. 필요하면 검색 사이트와 카테고리를 선택하고 가격 범위를 설정합니다.
  3. 결과의 출처와 등록일을 확인한 뒤, 상품 원문에서 현재 판매 상태와 거래 조건을 확인합니다.

데이터 출처와 정확도

검색 결과는 중고나라, 번개장터, 헬로마켓, 리씽크몰 등 각 사이트에서 공개한 목록을 기준으로 수집·정리합니다. 원문이 수정되거나 삭제되면 USED MARKET의 표시와 실제 판매 상태 사이에 차이가 생길 수 있습니다.

가격, 배송비, 구성품, 판매 가능 여부는 거래 전에 반드시 원문에서 다시 확인해 주세요. USED MARKET는 상품의 진품 여부, 판매자 신뢰도, 거래 성사를 보증하지 않습니다.

광고와 외부 링크

페이지의 광고는 상품 검색 결과와 별도로 표시됩니다. 광고 클릭을 유도하거나 광고를 상품 정보처럼 표시하지 않으며, 광고와 상품 출처는 서로 관련이 없습니다.

상품을 선택하면 해당 상품을 제공한 외부 사이트로 이동합니다. 결제, 배송, 환불 및 회원 이용은 각 외부 사이트의 정책과 판매자 조건을 따릅니다.

브라우저에 저장되는 정보

최근 검색어, 찜한 상품, 최근 본 상품은 편의를 위해 사용자의 브라우저 저장 공간에 보관됩니다. 회원가입이나 별도 계정 없이 사용할 수 있으며, 저장된 정보는 브라우저의 사이트 데이터 삭제 기능으로 지울 수 있습니다.

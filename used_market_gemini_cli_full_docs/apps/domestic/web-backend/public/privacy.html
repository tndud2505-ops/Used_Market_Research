개인정보처리방침

시행일: 2026년 8월 13일

1. 기본 원칙

USED MARKET(이하 “서비스”)는 회원가입 없이 중고상품 검색 기능을 제공합니다. 서비스는 검색과 운영에 필요한 최소한의 정보만 처리하고, 이용 목적이 끝난 정보는 관련 법령과 보안상 필요한 기간을 제외하고 지체 없이 삭제합니다.

2. 처리될 수 있는 정보

  • 검색어와 선택 조건: 검색 결과를 제공하기 위해 사용자가 입력한 검색어, 사이트, 카테고리, 가격 조건이 서비스 서버로 전송될 수 있습니다.
  • 브라우저 저장 정보: 최근 검색어, 찜한 상품, 최근 본 상품은 사용자의 브라우저 저장 공간에 저장되며 기본적으로 서비스 서버에 전송하지 않습니다.
  • 접속 기록: 서비스 보안과 장애 대응을 위해 접속 시각, IP 주소, 브라우저 정보 등이 호스팅·보안 인프라에 의해 자동 기록될 수 있습니다.
  • 광고 관련 정보: 카카오 애드핏 광고가 표시되는 경우 광고 제공 과정에서 쿠키 또는 광고 식별자 등 관련 정보가 처리될 수 있습니다. 자세한 내용은 카카오의 관련 정책을 따릅니다.

3. 이용 목적과 보관

처리된 정보는 검색 결과 제공, 서비스 품질 개선, 오류·부정 이용 방지, 광고 노출 및 통계 목적으로 사용됩니다. 브라우저 저장 정보는 사용자가 삭제하거나 브라우저 저장 기간이 끝날 때까지 보관됩니다. 서버 접속 기록은 호스팅·보안 운영 정책과 법령이 정한 기간을 따릅니다.

4. 외부 사이트와 제3자 서비스

검색 결과의 상품 링크를 선택하면 중고나라, 번개장터, 헬로마켓, 리씽크몰 등 외부 사이트로 이동합니다. 외부 사이트의 개인정보 처리와 쿠키 사용은 각 사이트의 정책이 적용됩니다. 서비스는 외부 사이트에 입력한 개인정보를 수집하거나 대신 관리하지 않습니다.

5. 이용자의 권리

사용자는 브라우저 설정에서 사이트 저장 데이터를 삭제할 수 있습니다. 개인정보 처리에 관한 문의나 삭제 요청은 서비스 운영자에게 전달해 주시면 확인 후 관련 절차에 따라 안내하겠습니다.

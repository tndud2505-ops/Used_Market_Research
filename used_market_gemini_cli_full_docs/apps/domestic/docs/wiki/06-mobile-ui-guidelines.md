# 모바일 UI 원칙

중고상품 검색 UI를 모바일에서 사용할 때 적용하는 기본 원칙이다. 모바일은 데스크톱 화면을 그대로 줄이는 것이 아니라, 사용자가 가장 자주 쓰는 기능을 먼저 남기고 나머지 영역은 접거나 줄여서 보여준다.

## 기본 방향

- 검색, 카테고리 선택, 결과 확인처럼 핵심 흐름을 화면 앞쪽에 둔다.
- 우선순위가 낮은 정보는 숨기거나 접는다. 한 화면에 모든 기능을 유지하지 않는다.
- 큰 영역은 모바일 높이를 과도하게 차지하지 않도록 축소·아코디언·가로 스크롤 중 하나로 바꾼다.
- 목록이 길어질 때는 페이지 전체가 길어지지 않도록 목록 영역에 내부 스크롤을 적용한다.
- 데스크톱의 3열 이상 그리드는 모바일에서 2열 또는 1열로 바꾼다.
- 모바일 화면에는 가로 스크롤이 생기지 않도록 한다. 단, 탭·필터·짧은 카테고리 레일처럼 가로 탐색이 자연스러운 영역은 예외로 둔다.

## 영역별 처리 규칙

### 1. 헤더와 검색

- 브랜드, 검색창, 검색 실행 버튼을 우선 노출한다.
- 헤더가 한 줄에 들어가지 않으면 검색창을 다음 줄로 내린다.
- 검색창과 실행 버튼은 화면 폭 안에서 줄어들 수 있어야 한다.
- 검색 결과가 표시된 뒤에도 검색창에 다시 접근하기 쉬워야 한다.

### 2. 카테고리

- 카테고리가 많으면 목록 전체를 그대로 펼쳐 화면을 길게 만들지 않는다.
- 기본 카테고리는 내부 세로 스크롤 목록으로 제한한다.
- 하위 카테고리는 부모를 선택했을 때만 펼친다.
- 카테고리 선택 영역이 너무 높아지면 주요 카테고리만 가로 스크롤로 먼저 보여주고, 세부 분류는 별도 펼침 영역으로 둔다.
- 선택된 카테고리와 현재 펼쳐진 위치가 분명해야 한다.

### 3. 상품 결과

- 모바일 기본 상품 그리드는 2열을 우선 검토한다.
- 상품명은 2줄 안에서 읽히도록 제한하고, 가격과 등록 시점은 항상 보이게 한다.
- 이미지 비율을 고정해 목록이 흔들리지 않게 한다.
- 찜, 원문 이동처럼 중요한 액션은 이미지 위 또는 상품 정보 가까이에 둔다.
- 필터와 정렬이 많으면 한 줄에 억지로 넣지 말고 줄바꿈하거나 접을 수 있게 한다.

### 4. 보조 영역

- 최근 본 상품, 부가 통계, 안내 문구처럼 핵심 검색에 직접 필요하지 않은 영역은 모바일에서 숨길 수 있다.
- 보조 정보가 꼭 필요하면 결과 아래에 두되, 빈 상태가 큰 공간을 차지하지 않게 한다.
- 큰 빈 상태 패널은 최소 높이를 줄이고, 필요한 안내만 남긴다.

## 큰 영역을 줄이는 방법

콘텐츠 성격에 따라 아래 순서로 선택한다.

1. **숨김**: 모바일에서 없어도 핵심 작업이 가능한 보조 영역
2. **접기**: 사용자가 필요할 때만 확인하는 필터·세부 카테고리·추가 정보
3. **내부 스크롤**: 항목 수는 많지만 같은 영역 안에서 탐색해야 하는 카테고리·필터 목록
4. **가로 스크롤**: 탭, 짧은 선택지, 비교 가능한 작은 항목
5. **세로 재배치**: 검색 결과처럼 핵심 콘텐츠는 순서를 유지하면서 한 열 또는 두 열로 변경

## 모바일에서 피할 것

- 데스크톱의 세 열 레이아웃을 폭만 줄여 글자가 찌그러지는 방식
- 카테고리 전체를 펼쳐 검색 결과가 화면 아래로 밀리는 방식
- 빈 상태인데도 큰 패널 높이를 유지하는 방식
- 작은 글씨와 작은 버튼으로 정보를 한 화면에 억지로 모두 넣는 방식
- 고정 요소가 검색창이나 상품 버튼을 가리는 방식
- 모달 안에 다시 긴 목록과 스크롤을 중첩하는 방식

## 검수 체크리스트

- 360~390px 폭에서 가로 넘침이 없는가?
- 첫 화면에서 검색과 핵심 카테고리에 접근할 수 있는가?
- 긴 목록은 내부 스크롤 또는 접힘으로 제한되는가?
- 우선순위가 낮은 영역이 큰 빈 공간을 만들지 않는가?
- 상품 카드가 2열에서 제목·가격·찜 버튼을 모두 보여주는가?
- 버튼과 목록 항목을 손가락으로 누르기 쉬운가?
- 키보드 포커스와 스크린 리더용 이름이 유지되는가?
- 검색·필터·카테고리 선택 후 화면이 갑자기 위아래로 튀지 않는가?

## 현재 적용 사례

- 모바일에서는 `최근 본 상품` 영역을 숨긴다. 검색 결과를 찾는 핵심 흐름에 필요하지 않고, 빈 상태일 때 화면 하단에 큰 공간을 만들기 때문이다.
- 카테고리 목록은 모바일에서 최대 높이를 제한하고 내부 세로 스크롤을 사용한다.
- 결과 상품은 모바일에서 2열 그리드로 표시한다.
- 데스크톱의 `최근 본 상품` 영역은 유지해 넓은 화면에서의 보조 탐색 기능은 보존한다.

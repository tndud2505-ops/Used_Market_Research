## 현재 진실 (2026-08-24)

- 운영 웹 기본 검색: 중고나라, 번개장터, 헬로마켓, 리씽크몰. 당근은 지역별 결과를 정확히 제공하지 못하는 공개 검색 경계 때문에 운영 대상에서 제외한다.
- 헬로마켓·리씽크몰도 메인 가격 통합 결과에 포함된다. 공식 카테고리 ID가 없으므로 검색어 없는 카테고리 탐색에서는 제외하고, 명시 검색어가 있을 때만 로컬 분류 필터를 거쳐 카테고리 검색에 참여한다.
- 사용자 검색은 `used-pick.com`의 Cloudflare Worker가 `runner.used-pick.com` Named Tunnel을 통해 AWS Node 러너로 전달한다. AWS SQLite가 주 검색 색인이고 D1은 장애 시 최근 10,000개 이하의 제한된 대체 경로다.
- 검색 색인은 사이트별 160개에서 시작해 사용자가 마지막 결과에서 요청할 때 320→480→640개로 확장한다. 전체 스냅샷은 최대 1,000개이며 화면은 30개씩 번호 페이지로 표시한다.
- 전체 검색 뒤 사이트 탭 전환은 새 검색이 아니다. 같은 수집 키의 스냅샷을 사이트로 즉시 필터링하고, 선택한 사이트만 320개 후보까지 비동기 보강한다.
- `낮은 가격`은 현재 결과를 즉시 숫자 가격순으로 재배열하고 같은 SQLite 스냅샷으로 교정한다. 정렬 변경만으로 원 사이트를 재수집하지 않는다.
- 전체 검색 뒤 사이트 탭은 기존 결과를 즉시 필터링하고 선택 사이트만 보강하며, 3페이지(90개)까지 미리 읽는다.
- 90개 선읽기가 끝나면 `1 2 3 4 … 마지막`을 표시한다. 1~3페이지는 즉시 이동하고 4페이지는 cursor 한 번만 조회한다. 먼 마지막 페이지는 총량 표시일 뿐 클릭할 수 없다.
- 운영 검색은 `cache_first`다. 저장 결과를 먼저 보여주고 stale이면 경과 시간을 표시한 채 백그라운드에서 갱신한다.
- 현재 실시간 수집은 공개 HTTP/API·HTML 경로를 사용하며 Cloudflare Workers 안에서 브라우저를 실행하지 않는다.
- 가격 그래프는 `GET /api/market/history`와 검색 응답의 `data.price_history`로 제공된다.
- 카테고리 연결은 `market/logic/category-harness.ts`가 사이트 등록부에서 계획과 검증 결과를 자동 생성한다.
- Cloudflare Worker와 AWS 러너는 운영 배포 대상이며, AWS 러너의 공개 HTTPS 경계는 Named Tunnel과 토큰으로 보호한다.

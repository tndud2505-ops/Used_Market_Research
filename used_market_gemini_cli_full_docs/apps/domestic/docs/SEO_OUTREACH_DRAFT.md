# USED MARKET 소개 게시물 초안

## 제목

중고나라·번개장터 매물을 한 번에 비교하는 중고매물 통합검색을 만들어봤습니다

## 본문

안녕하세요. 여러 중고마켓을 따로 검색하는 일이 번거로워서 중고매물 통합검색 서비스 `USED MARKET`을 만들었습니다.

중고나라·번개장터·헬로마켓·리씽크몰의 공개 매물을 한 번에 검색하고, 상품 가격과 출처를 비교할 수 있습니다. 아이폰, 노트북, 그래픽카드, 카메라, 게임기 같은 상품을 검색해 볼 수 있습니다.

사이트: https://used-pick.com/

검색 결과의 거래는 각 상품 원문 사이트에서 진행되며, 가격·판매 상태·구성품은 거래 전에 원문에서 다시 확인해야 합니다. 직접 만든 서비스라 검색 흐름이나 화면에 대한 피드백을 받고 있습니다.

## 게시 원칙

- 커뮤니티별 규칙을 먼저 확인하고, 같은 글을 여러 게시판에 반복해서 올리지 않습니다.
- 제목과 본문에 검색 키워드를 과도하게 반복하지 않습니다.
- 직접 개발·운영한 서비스라는 점과 외부 거래 링크가 포함된다는 점을 밝힙니다.
- 광고나 제휴가 있는 경우 해당 게시판의 광고·홍보 규칙에 맞게 표시합니다.

# USED-PICK 메인보드 분류·가격 통계 독립 검토 프롬프트

아래 사이트의 메인보드 분류와 가격 비교 품질을 독립적으로 감사해 주세요. 구현자의 설명을 그대로 믿지 말고, 실제 UI와 공개 API 응답을 근거로 결론을 내리세요.

## 검사 대상

- 서비스 홈: https://used-pick.com/
- 컴퓨터 맞추기: https://used-pick.com/computer-builder.html
- 가격 분석: https://used-pick.com/price-analysis.html
- 메인보드 카탈로그 API: https://used-pick.com/api/pc/products?category=MOTHERBOARD&limit=100

  https://used-pick.com/api/pc/listings?canonical_product_id=motherboard%3Aplatform%3Aamd%3Aasus&limit=100
- 예시 매물 API — MSI AMD:
  https://used-pick.com/api/pc/listings?canonical_product_id=motherboard%3Aplatform%3Aamd%3Amsi&limit=100
- 예시 매물 API — ASUS Intel:
  https://used-pick.com/api/pc/listings?canonical_product_id=motherboard%3Aplatform%3Aintel%3Aasus&limit=100

읽기 전용으로 검사하세요. 로그인, 피드백 제출, 데이터 수정, 구매·판매 사이트의 상태 변경은 하지 마세요. 검사 시각과 확인한 URL을 기록하세요.

저장소에 접근할 수 있다면 다음 파일도 확인하세요. 접근할 수 없다면 사이트와 공개 API만으로 감사해도 됩니다.

## 검토 목적

1. 현재 시스템이 메인보드를 어떤 단계와 키로 분류하는지 역추적하세요.
2. 현재 한 항목으로 묶인 매물들이 실제로 같은 제품인지 판단하세요.
3. 일반 사용자가 중고 메인보드를 찾고 가격을 비교할 때 기대하는 자연스러운 분류 체계를 제안하세요.
4. 현재 평균·중앙값·참고가격이 어떤 범위의 제품을 대표하는지, 가격 비교 지표로 사용 가능한지 검증하세요.
5. 잘못 합쳐진 제품, 잘못 나뉜 동일 제품, 액세서리·세트·고장품·해외 가격 혼입을 찾아내세요.

## 독립적으로 검증할 가설

다음은 확정 사실이 아니라 우선 검증할 가설입니다. 반대 증거가 있으면 반박하세요.

- `ASUS AMD Desktop Motherboard Platform` 같은 항목이 정확한 제품이 아니라 제조사와 CPU 플랫폼만 나타내는 탐색용 묶음일 수 있다.
- `ROG STRIX B550-A GAMING`, `TUF GAMING B550-PRO`, `PRIME B550M-A`가 `B550` 또는 ASUS AMD 하나로 과도하게 합쳐질 수 있다.
- `B550`, `X570`, `X870E`처럼 가격대가 완전히 다른 칩셋이 한 가격 통계에 들어갈 수 있다.
- `B450M 메인보드용 IO 실드` 같은 액세서리가 완제품 메인보드로 통계에 포함될 수 있다.
- KRW 국내 매물과 USD 해외 매물이 같은 목록에서 충분한 구분 없이 보일 수 있다. 단, 실제 통계 계산은 시장 풀별로 분리될 수도 있으므로 목록 표시와 통계 집계를 따로 검증해야 한다.
- 코드의 `exact_model`이 실제 전체 모델명이 아니라 칩셋 토큰만 담을 수 있다.

## 표본 검사 방법

최소 30개 매물을 직접 검토하되 다음을 고르게 포함하세요.

- AMD와 Intel 플랫폼
- ASUS, MSI, GIGABYTE, ASRock 등 여러 제조사
- 보급형·중급형·고급형 칩셋
- 이름에 `M`, `I`, `E`, `D4`, `DDR4`, `DDR5`, `WIFI`, `WI-FI`, `AX`, `V2`, `II`가 포함된 변형
- 국내 C2C, 판매업자, 해외 매물
- 정상 중고, 새 제품, 고장·미확인, 세트·번들, 박스·백패널·IO 실드 같은 액세서리

각 표본에 다음 열을 기록하세요.

| 항목 | 내용 |
|---|---|
| 원문 제목·URL | 판매글 원문과 링크 |
| 사이트·통화·가격 | 출처, KRW/USD 등, 표시 가격 |
| 현재 분류 | `canonical_product_id`, 표시명, `spec_group_id`, 모델·제조사·조건·통계 포함 여부 |
| 사람이 판단한 정답 | 제조사, 플랫폼/소켓, 칩셋, 정확한 제품명, 주요 변형 |
| 매물 성격 | 단품, 동일 제품 복수, 번들, 완본체, 액세서리, 박스만, 구함, 고장품 등 |
| 판정 | 정확, 과병합, 과분할, 오분류, 통계 제외 필요 |
| 근거 | 어떤 단어와 사양 때문에 그렇게 판단했는지 |

API 필드가 비어 있거나 서로 모순되면 그대로 기록하세요. 제목만으로 확정할 수 없는 경우 억지로 모델을 만들지 말고 `불명확`으로 표시하세요.

## 일반 사용자가 기대하는 권장 분류 기준

아래 구조가 실제 매물과 사용자 검색 습관에 맞는지 평가하고, 필요하면 수정안을 제시하세요.

1. 부품 종류: 메인보드
2. 제조사: ASUS, MSI, GIGABYTE, ASRock 등
3. CPU 플랫폼과 소켓: AMD/Intel, AM4/AM5/LGA1700 등
4. 칩셋: B550, B650, X570, B760, Z790 등
5. 정확한 제품명: `ASUS ROG STRIX B550-A GAMING`처럼 제조사·라인·모델 전체
6. 가격을 실제로 갈라놓는 변형: ATX/M-ATX/Mini-ITX, DDR4/DDR5, Wi-Fi 유무, 리비전·세대
7. 상태와 판매 단위: 정상 중고/신품/리퍼/고장/미확인, 단품/복수/번들/액세서리
8. 시장과 통화: 국내 C2C, 국내 판매업자, 해외 시장을 분리

`B550`은 제품명이 아니라 칩셋 계층으로 취급하는 것이 타당한지 특히 판단하세요. 하이픈·공백·한글 별칭 차이는 같은 정확한 SKU로 정규화하되, `B550-A`와 `B550M-A`, `D4`와 DDR5판, Wi-Fi판과 비 Wi-Fi판, 리비전 차이를 무조건 합치지 마세요.

## 가격 통계 검토 기준

- 정확한 SKU 가격은 동일 SKU끼리만 계산하는가?
- 칩셋·플랫폼 facet에는 가격 통계가 제공되지 않고 `EXACT_MODEL_REQUIRED` 빈 응답이 반환되는가?
- 활성 매물과 판매 완료 가격이 분리되는가?
- 정상 중고, 신품, 리퍼, 고장·미확인이 분리되는가?
- 국내 C2C, 판매업자, 해외 시장과 통화가 분리되는가?
- 단품 가격에 번들, 완본체, 액세서리, 박스만 판매가 들어가지 않는가?
- 평균이 극단값에 끌려가는 경우 중앙값, 사분위 범위, 절사 또는 이상치 표시가 필요한가?
- 표본이 부족할 때 값을 숨기거나 상위 범주 참고값으로 낮춰 표시하는가?

가격 차이가 크다는 사실만으로 오분류라고 단정하지 마세요. 동일 SKU라도 상태, 구성품, 보증, 지역, 판매 시점 때문에 차이가 날 수 있습니다. 반대로 이름이 비슷하다는 이유만으로 다른 SKU를 합치지도 마세요.

## 필수 결과물

다음 순서로 한국어 보고서를 작성하세요.

1. **한 줄 결론**: 현재 분류가 `가격 비교용으로 적합 / 제한적으로 적합 / 부적합` 중 어디인지
2. **현재 분류 구조**: UI와 API에서 확인한 실제 계층과 식별 키
3. **증거 표**: 실제 URL이 포함된 최소 30개 표본 판정
4. **정량 평가**
   - 정확한 모델 추출률
   - 과병합률과 과분할률
   - 액세서리·번들·완본체 오염률
   - 상태·시장·통화 혼입률
   - 통계 포함 여부의 정확도
   - 지표의 분모와 계산 방법
5. **대표 오류 사례**: 사용자 가격 판단을 가장 크게 왜곡하는 사례 10개 이내
6. **권장 목표 분류 체계**: 필드 정의와 예시 식별자 포함
7. **가격 통계 정책**: exact SKU와 상위 범주 통계의 분리 규칙
8. **개선 우선순위**
   - P0: 잘못된 가격 판단을 직접 만드는 문제
   - P1: 검색·탐색 정확도를 낮추는 문제
   - P2: 표시와 설명 개선
9. **수용 테스트**: 수정 후 자동·수동으로 확인할 구체적 사례와 기대 결과
10. **확인 불가 사항**: 접근 제한이나 표본 부족으로 판단하지 못한 내용

## 중요한 판단 원칙

- 카테고리 판정, 정확한 SKU 판정, 탐색용 상위 묶음, 가격 통계 집계를 서로 다른 문제로 평가하세요.
- UI 표시명 때문에 같은 모델처럼 보이는 문제와 실제 데이터가 같은 통계에 합쳐진 문제를 구분하세요.
- 공개 API와 원문 매물 간 불일치를 증거로 남기세요.
- 작은 표현 차이보다 사용자에게 잘못된 시세를 보여주는 과병합, 통화 혼입, 액세서리 혼입을 우선하세요.
- 근거 없는 추측은 사실처럼 쓰지 말고 `확인`, `추론`, `미확인`으로 표시하세요.
- 최종 결론에는 현재 방식에서 유지할 부분과 반드시 바꿀 부분을 각각 명시하세요.

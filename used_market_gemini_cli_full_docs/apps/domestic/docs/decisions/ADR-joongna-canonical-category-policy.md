# ADR: 중고나라 기준 canonical 카테고리 정책

- 상태: 적용
- 결정일: 2026-08-14
- 정책 버전: `joongna-primary-v1`

## 결정

서비스의 canonical 카테고리와 화면의 1차 분류는 중고나라 검색 메뉴에서 확인된 21개를 기준으로 고정한다.

중고나라 기준 21개는 다음과 같다.

`수입명품`, `패션의류`, `패션잡화`, `뷰티`, `출산/유아동`, `모바일/태블릿`, `가전제품`, `노트북/PC`, `카메라/캠코더`, `가구/인테리어`, `리빙/생활`, `게임`, `반려동물/취미`, `도서/음반/문구`, `티켓/쿠폰`, `스포츠`, `레저/여행`, `중고차`, `오토바이`, `공구/산업용품`, `무료나눔`.

중고나라 URL의 숫자는 원본 사이트 ID로만 보관한다. 예를 들어 `category=19`는 canonical `motorcycle`과 연결하고, 서비스 내부 요청은 숫자 `19`가 아니라 `motorcycle`을 사용한다. 메뉴와 검색 결과에서 확인되지 않은 `18`은 추가하지 않는다.

## 사이트 통합 규칙

1. 다른 사이트에서 공식 카테고리 ID와 경로가 확인되면 해당 canonical에 매핑한다.
2. 여러 공식 ID가 하나의 canonical을 구성하면 `aggregate_exact`로 합산한다.
3. 부모 ID만 확인된 자식은 `parent_fallback`으로 기록하되 선택 불가로 둔다.
4. 공식 경로가 없는 사이트는 키워드 검색을 할 수 있어도 category mode에는 통합하지 않는다.
5. 여러 카테고리를 한 번에 요청할 때는 요청한 모든 카테고리에 공식 경로가 있는 사이트만 호출한다.

## 현재 확인 결과

| 사이트 | 공식 매핑 | category mode |
| --- | ---: | --- |
| 중고나라 | 21개 1차 + 확인된 패션 하위 | 사용 |
| 번개장터 | 17개 1차 + 확인된 패션 하위 | 공식 매핑이 있는 항목만 사용 |
| 헬로마켓 | 0개 | 사용하지 않음. 키워드 검색만 별도 취급 |
| 리씽크몰 | 0개 | 사용하지 않음. 키워드 검색만 별도 취급 |

번개장터에서 공식 경로가 확인되지 않은 중고나라 기준 카테고리는 `수입명품`, `레저/여행`, `중고차`, `무료나눔`이다. 이 목록은 매핑이 확인될 때까지 번개장터 category mode에서 제외한다.

## 근거와 검증

- 원본 매핑: `market/logic/category-catalog.ts`
- 배포용 매핑: `cloudflare/category-source-map.mjs`
- API 표시 계획: `GET /api/categories`의 `site_plans`, `source_bindings`
- 분류 기록 생성: `npm run category:record`
- 계약 검증: `npm run category:harness`
- 실제 API 카테고리 검증: `npm run category:live`
- 사이트별 매트릭스 검증: `npm run category:matrix:live`
- 브라우저 검증: `npm run browser:contract`

실제 사이트의 빈 결과·접속 제한·429는 매핑을 자동으로 official로 승격시키는 근거가 아니다. 해당 실행의 warning/error로만 기록하고, 공식 URL·ID가 다시 확인될 때만 매핑을 변경한다.

# ADR: 가격 통계와 수익화 경계

- 상태: 채택
- 날짜: 2026-08-29

## 2026-11-12 하단을 자사 앱 배너로 교체

운영자가 실제 수익이 낮은 광고 하나를 트레인갤러리 광고로 바꾸도록 요청했다. AdFit에서 2026-10-15~11-11의 같은 28일을 조회해 하단 단위 적립금110원, 오른쪽174원을 확인하고 단위 코드와 대조했다. `DAN-gvTVDnxVn9S3leR5`만 세 주요 페이지의 본문 뒤에서 자사 앱 배너로 교체한다. AdFit 계정의 단위·보고서와 오른쪽 `DAN-gG0WEoycq7Nup5kT`는 보존한다.

자사 배너는 기존 콘텐츠 자격 신호로 표시·숨김하며 유료 SDK나 노출 콜백을 요청하지 않는다. PC 그림 영역은 최대960×140, 모바일은 최대360×120이다. KSTOCK에서 제공한 실제 앱 캡처와 4.5초 무음 운동 장면을 재사용한다. 영상은 보이는 PC 화면에서만 자동 재생하고 한 번 끝나면 반복하지 않으며, 화면 밖·백그라운드·부적격 콘텐츠에서는 멈춘다. 동작 줄이기 설정은 정지 화면을 기본으로 하고 명시적인 재생 버튼만 허용한다. 사용자가 멈춘 영상은 자동으로 재시작하지 않는다. 링크에는 자사 앱 광고 표시와 `sponsored noopener noreferrer`를 유지하고 Google Play의 검증된 앱 패키지로만 연결한다. 가격 통계·검색 순서·수집에는 관여하지 않는다.

후속 사용자 요청에 따라 같은 PC 배너의 모아곰 팔·아령을 인라인 SVG로 바꾸고 2.25초씩 두 번 움직인다. 실제 영상 play/pause/ended 상태와 연동하며, 종료 후 명시적 다시 재생 때만 SVG를 교체해 동작을 처음부터 시작한다. 동작 줄이기 환경의 사이트 전체 애니메이션 중단 규칙은 유지하고, 사용자가 재생을 누른 배너의 팔에만 예외를 둔다. 모바일 대체·광고 단위·배치·Worker 설정은 유지한다.

## 2026-10-14 애드핏 통일(당시 결정)

운영자 요청에 따라 공개 화면 광고를 카카오 AdFit으로 통일한다. 아래 과거 Adsterra·제휴 링크 표시 결정은 현재 UI에 적용하지 않는다. 기존 제휴 API·집계 보존 및 보안 경계는 유지하되 공개 화면에서 호출하거나 광고를 표시하지 않는다.

중고 시세·컴퓨터 맞추기·가격 분석은 본문 뒤에 기존 320×100 단위 `DAN-gvTVDnxVn9S3leR5`를 표시한다. 최초 진입 시 1360px 이상 화면에는 별도로 기존 160×600 단위 `DAN-gG0WEoycq7Nup5kT`를 오른쪽에 표시한다. SDK는 한 번만 불러오고 단위별 NO-AD 콜백을 분리한다. 검색 결과가 없거나 도구 초기화가 실패하면 광고를 요청하지 않는다. 광고 로딩 실패·미충전 시 공간을 접고 광고 노출은 가격 통계·추천순에 영향을 주지 않는다.

## 이전 결정

가격 통계·추천순·검색 결과는 광고와 독립적으로 계산한다. 문맥형 제휴 링크는 정확한 PC 상품 또는 카테고리 목적지가 검증된 경우에만 별도 모듈에 표시한다. Adsterra 네트워크 배너는 승인된 `used-pick.com`의 검색 결과 페이지에 300×250 한 슬롯만 허용하며, 유기 매물과 페이지네이션 뒤의 단일 배치에서만 표시한다. 범용 목적지 제휴 링크, 초기 화면 광고, 결과 없음 광고, 가격/기준가격 영역 광고는 허용하지 않는다.

2026-09-08 운영자의 쿠팡 파트너스 연결 요청에 따라, 해당 계정의 `used-pick.com` 등록과 실제 부품 검색 결과를 확인하고 7개 공개 부품군의 간편 링크를 발급했다. 운영 설정에서 이 검토된 링크만 활성화한다. 생활용품 배너·우측 배너·빈 결과 CTA는 계속 금지한다. 단일 모델 전용 링크가 없는 경우 부품군 전체 상품이며 선택 모델과 다를 수 있음을 표시한다.

## 필수 경계

- 제휴 링크는 `rel="sponsored noopener noreferrer"` 또는 동등한 referrer 차단을 사용한다.
- 링크 바로 옆에 수수료 고지와 시세·추천순 무관 문구를 둔다.
- 제휴 가격과 `OPTION_AD` 매물은 통계 표본에 포함하지 않는다.
- 측정 이벤트에는 원문 검색어, 상품명, 전체 URL, 자유 입력, 영구 사용자 ID를 저장하지 않는다.
- 고지 누락, 허용되지 않은 목적지, 통계 오염은 fail-closed로 차단한다.

## 활성화 계약

- `AFFILIATE_ALLOWED_ORIGINS`에 등록된 HTTPS origin과 `AFFILIATE_OFFERS_JSON`의 승인·검토일·만료일을 모두 통과해야 한다.
- offer는 하나의 정확한 `canonical_product_id` 또는 `category_code`에만 연결한다. `/` 홈페이지와 범용 fallback은 거절한다.
- Worker는 유기 매물 응답과 별도인 `/api/monetization/contextual-offer`에서 offer를 최대 1개 반환한다. UI는 유기 결과와 페이지네이션 뒤의 전용 영역에만 표시한다.
- 전역 kill switch는 `MONETIZATION_ENABLED`이며 잘못된 JSON, 미승인·만료 offer, origin 불일치 때는 오류 대신 모듈을 숨긴다.
- `MONETIZATION_EVENT_SECRET`은 32바이트 이상의 운영 secret으로만 설정한다. 누락·부족 시 offer를 숨기며, 짧게 만료되는 HMAC event token 검증을 통과한 노출·클릭만 집계한다.
- 운영 secret은 소스나 `wrangler.jsonc`에 넣지 않고 `npx wrangler secret put MONETIZATION_EVENT_SECRET --config cloudflare/wrangler.jsonc`로 저장한 뒤 kill switch를 켠다.
- 사이트의 파트너스 계정 등록, 정확한 제휴 목적지, 쿠팡 수수료 고지와 운영 secret을 확인한 뒤 활성화한다. 본인 인증 및 쿠팡의 최종 승인 여부는 사이트의 링크 동작과 구분하며 운영자가 계정에서 완료한다.
- 측정은 `offer_id`, slot, 제품/카테고리 문맥별 일일 노출·클릭 합계만 저장하고 180일 후 삭제한다. 원문 검색어·상품명·전체 URL·IP·영구 사용자 ID는 측정 원장에 넣지 않는다.
- event token에는 짧게 만료되는 무작위 ID를 포함하고, 같은 token의 동일 이벤트 재사용은 dedup 원장에서 거절한다. 만료 token과 180일 초과 집계는 이벤트 유입 여부와 무관하게 scheduler가 정리한다.
- 운영자 bearer secret 비교는 고정 길이 digest를 사용한다. 공개 스모크가 실패하면 release 명령은 Wrangler의 직전 Worker 버전 rollback을 자동 실행한다.
- Adsterra 태그는 검색 결과가 있고 사용자가 광고 쿠키에 동의한 뒤에만 불러온다. 태그 코드는 Adsterra가 발급한 값을 그대로 사용하고, 게시 전에 그 태그의 호스트만 CSP에 허용한다. Popunder, Social Bar, Smartlink, 성인 광고는 사용하지 않는다.
- 광고 여부는 가격 통계·추천순에 영향을 주지 않는다. 광고 제공자의 쿠키와 가명 기기·브라우저 및 노출·클릭 측정 처리는 개인정보 안내와 광고 쿠키 설정에서 고지한다.

## 2026-09-08 검토한 목적지

운영 설정의 `AFFILIATE_OFFERS_JSON`은 JSON 문자열과 Wrangler JSON 배열 모두 지원한다. 링크는 해당 파트너스 계정의 간편 링크 생성 화면에서 발급했으며, 원래 검색 페이지를 확인했다. 광고 링크를 반복 클릭하여 실적을 만들지 않는다.

## 후속 순서

무광고 기준선을 측정한 뒤 정확한 PC 문맥 제휴 모듈 1개, 목표가 알림의 프리미엄 수요, PC 모델별 고유 통계 콘텐츠 기반 수동 광고, 집계 데이터 권리와 SLA가 확인된 B2B 순으로 검토한다.

## 2026-11-12 원본 모아곰 후속 교체

SVG 재현본 대신 소유 원본 PNG의 포스터와 오프라인 Remotion 렌더 MP4를 사용한다. 모아곰 video가 4.5초 재생의 기준이며 운동 장면 video는 함께 재생·정지한다. 광고 위치와 기존 자격/동작 줄이기/사용자 정지/비반복 조건은 유지한다. Remotion은 제작 도구로만 사용하고 웹 런타임 의존성은 추가하지 않는다. 세 화면의 변경은 광고 표시로 한정하며 PWA·앱 광고 분기·Worker/API·매물/통계에는 영향을 주지 않는다.

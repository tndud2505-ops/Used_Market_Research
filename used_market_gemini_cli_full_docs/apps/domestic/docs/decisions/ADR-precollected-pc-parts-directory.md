# ADR: 사전수집형 PC 부품 디렉터리

상태: 운영 적용, 이력 누적 중  
결정일: 2026-08-30  
최종 갱신: 2026-09-01

## 결정

USED-PICK의 기본 PC 화면은 원 사이트 실시간 검색을 실행하지 않는다. 단일 source registry에서 정책과 운영이 모두 승인된 사이트만 AWS Runner가 기존 사이트별 스크립트로 미리 수집하고, 공개 화면은 검증된 publication의 catalog·listing·stats projection만 조회한다. 기존 `/api/search`는 rollback용 legacy 경로로 유지한다.

사용자 탐색 순서는 `부품군 → 제품군·규격·용량 → 제조사 → 정확 모델 → 사이트`다. 제품 master와 탐색 facet은 버전으로 관리하며, 공개 catalog·listing·stats는 동일 publication 버전과 `as_of`를 사용한다. 화면은 좌측 필터의 선택값으로 가운데 사이트별 매물 결과와 오른쪽 가격 요약·30일 그래프를 같은 범위로 갱신한다.

## 제품 식별

- GPU는 `chip_manufacturer`와 `board_manufacturer`를 분리한다.
- CPU suffix는 제품 identity다. K, KF, F, T, X, X3D, G 모델을 합치지 않는다.
- RAM은 모듈 용량·모듈 수·총용량·개당/일괄 가격범위를 분리한다.
- SSD의 M.2는 form factor, NVMe는 protocol로 저장한다.
- 메인보드 revision과 PSU watt·revision은 정확 모델 identity에 포함한다.
- 미등록 제조사와 모델은 후보로 남기며 기존 제품에 추측해서 합치지 않는다.

## 사전수집

전문 사이트의 허용된 카테고리 목록은 매시간 증분 수집한다. 범용 사이트는 거래량 높은 모델을 매시간, 최근 관측 모델을 6시간마다, 전체 master를 하루 한 번 분할 순회한다. 사용자 요청은 수집 target을 생성하거나 즉시 실행하지 않는다.

운영 디렉터리 source는 중고나라·번개장터·다나와 장터·헬로마켓·리씽크몰·eBay·쿨엔조이 7개다. 다나와의 PC 주요부품과 주변기기 카테고리는 11개 부품군에 직접 매핑한다. 리씽크몰은 `KR_REFURB_RETAIL`, eBay는 `OVERSEAS_USED`로 분리하며 국내 개인 중고 통계와 합치지 않는다.

검색형 source는 매시간 11개 부품군의 19개 대표 검색을 먼저 수행하고, versioned master 전체를 24시간 간격으로 분할 순회한다. 현재 target set은 `pc-targets:2:full-master-v5`이며 총 955개 target이다. 공개 API 요청은 이 target을 실행하지 않는다.

정상 공개 요청에도 HTTP 403을 반환하는 시점에는 우회·로그인·captcha 처리를 하지 않는다. 해당 source만 backoff·격리하고 마지막 정상 publication을 유지한다. 쿨엔조이는 공개 목록에서 확인되는 명시적 판매/판매완료 상태만 기록한다.

## 가격

현재 매물은 최신 유효 ACTIVE 관측의 평균·중앙값·표본 수를 제공한다. 판매완료는 최초 명시 SOLD 직전 마지막 표시가격의 평균·중앙값·표본 수를 제공한다. 이 값은 실제 체결가가 아니다. 실제 체결가격은 출처가 구조적으로 제공할 때만 `확인된 체결가`로 별도 저장·표시한다.

통합 통계는 동일한 market pool·condition·currency 안에서 원장 구성원을 직접 집계한다. 사이트 평균의 단순 평균은 사용하지 않는다. 표본이 3개 미만이면 대표가격을 공개하지 않는다.

## 공개 완료 기준

다음 조건을 모두 생산 데이터와 브라우저에서 확인해야 완료로 판정한다.

- 카탈로그: 11개 부품군의 모든 공개 노드는 안정적인 ID, 부품군, 제조사, `PRODUCT|BROWSE_BUCKET|BROWSE_FACET` 유형과 해당 비교 규격을 가진다. GPU는 칩 제조사와 보드 제조사를 합치지 않는다.
- 매물 포함: 제목과 구조화 카테고리가 같은 부품을 가리키고, 명시된 정확 모델 또는 `제조사 + 용량·세대·규격` 탐색 노드에 연결되며, 가격이 0보다 커야 한다. 추측한 제조사·용량·모델은 공개 가격 표본에 넣지 않는다.
- 노이즈 차단: 자동차 Dodge Ram, 휴대폰·가방 케이스, 일반 영단어 `odd`, 완제품 PC·노트북, 박스만·액세서리·구매글·옵션광고는 PC 부품 결과와 통계에 0건이어야 한다.
- 다중 매물과 중복: 같은 제품의 서로 다른 판매자 매물은 모두 표시한다. 같은 사이트의 같은 `source_listing_id` 또는 같은 eBay 공식 item ID는 한 번만 표시·집계한다. 교차 사이트는 확정된 중복 cluster만 통계에서 한 표본으로 센다.
- 필터: `부품 → 세대·용량·규격 → 제조사 → 제품 → 사이트`를 바꿀 때 모든 결과가 선택 조건을 만족해야 하며, 선택 조건과 맞지 않는 제목은 0건이어야 한다.
- 가격 통계: 동일 `canonical_product_id + market_pool + condition + currency`만 집계한다. ACTIVE는 매물별 하루 마지막 유효 관측 한 번, SOLD는 최초 SOLD 날짜 한 번만 센다.
- 가격 공개: `n<3`은 대표가격 없음, `n=3~4`는 중앙값과 경고, `n>=5`는 평균·중앙값, `n>=10`은 절사평균·IQR을 제공한다. 판매완료 가격은 실제 체결가가 아니라 마지막 표시가격이라고 고지한다.
- 그래프: 최근 30일 일별 현재 중앙값·판매완료 마지막 표시가격 중앙값과 각각의 표본 수를 함께 표시한다. 표본이 없는 날짜를 0원으로 만들거나 임의 보간하지 않는다.
- 운영: 공개 API는 외부 사이트를 호출하지 않는다. 승인된 source의 최근 수집, 분류 version, listing publication과 stats publication이 일치하고, checksum·행 수 검증을 통과한 자료만 활성화한다.

## 호환성과 복구

기존 제품 ID와 `legacy_general` 검색 projection은 삭제하지 않는다. 새 catalog/listing/stats publication이 불완전하거나 버전이 섞이면 이전 active publication을 유지한다. 운영 전환 전에는 scheduler 활성화, 최근 수집 성공, publication 버전 일치와 거짓 SOLD·시장군 혼합 0건을 확인한다.

## 현재 확인 결과

- V2 디렉터리는 11개 부품군, 760개 제조사별 제품·탐색 노드를 제공한다.
- 다나와 장터는 CPU·GPU·RAM·메인보드·SSD·HDD·PSU·쿨링·케이스·확장카드·ODD의 구조화된 카테고리 target을 사용한다.
- 2026-08-30 실제 category canary에서 11개 부품군 모두 목록 수집을 확인했다. 이후 생산 감사에서 다나와의 일부 카테고리 응답 실패와 eBay 광범위 검색어 노이즈가 확인되어 보강 중이다.
- 공개 화면은 `/api/pc/catalog`, `/api/pc/products`, `/api/pc/listings`, 제품별 30일 통계만 사용한다.
- RAM은 DDR 세대·모듈 용량·제조사, SSD/HDD는 용량 구간·제조사, GPU는 칩 제조사·세대·VRAM과 완제품 제조사 매물 필터를 분리한다.
- 카탈로그·제품·매물 API가 원 사이트 수집 함수를 호출하지 않는 계약은 `harness/pc-service-contract.mjs`에서 검증한다.
- Worker와 AWS scheduler는 운영 배포됐고, 공개 catalog에는 위 8개 source가 모두 노출된다. 30일 차트는 임의 과거값을 만들지 않고 실제 관측이 쌓인 날짜부터 채운다.
- 2026-09-01 운영 재분류에서 완제품·노트북·다부품 묶음 56건을 ACTIVE 수명주기는 보존한 채 가격 표본에서 제외했다.

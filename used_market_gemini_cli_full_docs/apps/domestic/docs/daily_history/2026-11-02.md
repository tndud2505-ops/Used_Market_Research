# 2026-11-02 — 모바일 검색·차트·부품 선택

실제 배포 영수증과 당시 브라우저 화면으로 확인한 UI 변경을 2026-11-03에 소급 정리했다. 다른 작업의 미확인 변경을 포함하지 않는다.

- 매물 검색을 모바일 한 줄 선택과 간단한 결과 행으로 바꿨다. 결과에는 검색 건수만 표시하고 반복 통계 안내와 별도 가격 그래프 버튼을 제거했다. 확인된 Worker: `511be53e-5819-4710-8cb8-be3c21112d79`, `1702dfc2-5c42-4cef-92d8-0aa68d999ce2`.
- 가격 분석은 모델·사이트·가격 종류를 한 줄에 배치하고, 사이트별 체크·최근 가격을 차트 위로 옮겼다. 모바일 가격축을 줄이고 확대·축소 버튼을 제거했으며 핀치·드래그와 전체 화면을 연결했다. 컴퓨터 시세는 선택한 가격만 부품 행에 표시한다. 확인된 Worker: `3390c810-ac7b-4ed4-83e4-d71991b8aefe`.
- 상세 필터와 가격/부품 모델 선택을 종류별 상단 탭과 체크 목록으로 바꿨다. 긴 목록만 스크롤하고 제목·하단 동작은 고정했다. 모바일에서 검색창을 자동으로 포커스하지 않으며, 부품 교체 시 수량과 다른 종류의 선택을 유지했다. 확인된 Worker: `dadd6234-ec46-44de-8afd-ccbc414a6fff`.
- 해당 UI 릴리스는 당시 운영본을 기준으로 분리한 정적 파일만 반영했다. 가격 계산·통화·분류 기준은 바꾸지 않았다. 실제 배포, 양 도메인 파일 대조, IAB 모바일/데스크톱 확인과 기존 UI·차트 계약 검증을 마쳤다.

지속적으로 보존하는 화면과 사용자용 설명은 [공개 패치 내역](../../web-backend/public/changelog.html)의 2026.11.02 항목 및 `web-backend/public/changelog/2026-11-02-*.png`를 따른다. 설계 근거는 `docs/design/2026-11-02-mobile-search`, `2026-11-02-mobile-tools`, `2026-11-02-tab-picker`에 있다. 당시 영수증은 저장소의 `.release-staging`에 있으며, 이 기록은 그 임시 디렉터리가 유지된다는 가정에 의존하지 않는다.

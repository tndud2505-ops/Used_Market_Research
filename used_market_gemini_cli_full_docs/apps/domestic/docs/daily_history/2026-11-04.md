- 데스크탑 모델 선택 화살표가 "모델 선택" 글자까지 포함한 영역의 세로 중앙에 그려져 상자보다 위로 치우쳤다. 판매 구성은 브라우저 기본 화살표라 모양이 달랐다. 두 상자 모두 상자 안에 같은 화살표를 그리도록 바꿨다.
- 판매 구성(기본 단품)을 목록 위에서 상세 필터 맨 위로 옮겼다. 기본 단품 필터는 노트북·본체·세트가 부품 목록에 섞이지 않게 하므로 유지했다. 모바일에서는 목록 위 한 줄이 줄고 필터 창 안에 한 줄로 들어간다.
- 데스크탑의 "모델 선택" 제목은 상자 안 문구(전체 모델 · 187개, 선택한 모델명)와 겹쳐 화면에서 숨기고 화면 낭독기용 이름으로만 남겼다. 1440px에서 모델 상자와 거래 사이트가 한 줄이 되고 아래 내용이 27px 올라간다. 좁은 폭에서는 거래 사이트가 다음 줄로 내려간다. Worker `a8d3a029-e00c-40fc-a395-920882aa825b`로 배포하고 운영 1440px에서 확인했다.
- 검증: `npm test` 통과. 운영 페이지에 새 HTML·CSS를 끼워 데스크탑·390px에서 화살표 위치, 완제품 전환(RTX 5090 101건→27건), 가로 넘침·앱 오류 없음을 확인했다.
- Worker: 첫 배포(`d0a93fb9`)는 수집 회차 중 러너 읽기가 5초를 넘겨 공개 확인이 503을 받았고 자동으로 `4a04080a`로 되돌아갔다. 상태 확인이 200으로 돌아온 뒤 같은 준비본으로 `aace6503-9cd1-493e-9b72-964d7220af9f`를 배포했다.
- 공개 패치 내역: 11-04 "메인보드를 CPU 소켓으로 찾기", "판매 구성은 상세 필터에서 선택"(운영 390px 캡처). Worker `5df50773-b3a1-49f5-8e81-f4a53d704191`로 배포하고 데스크탑·모바일에서 항목 열기, 이미지 로드, 원본 링크를 확인했다.

## 완제품 PC 목록 제외

- 결정: USED PICK은 PC 부품 시세 사이트라 완제품 PC·노트북을 볼 선택지를 없앴다. 이 매물들은 부품 검색어(예: RTX 5090)로 함께 수집된다. 운영 판매중 기준 그래픽카드 단품 5,095건에 완제품 2,542건, CPU 단품 3,668건에 완제품 448건이 함께 잡혀 있었다(카테고리별로 세어 중복 포함).
- 수정: 공개 판매 구성을 `SINGLE`(기본)과 `BUNDLE`로 한정했다(`PUBLIC_SALE_COMPOSITIONS`). 화면 선택지에서 전체 구성·완제품을 뺐고, 예전 `sale_composition=COMPLETE_PC` 링크는 단품으로 연다. 사이트 API는 `ALL`·`COMPLETE_PC`를 400으로 거부한다. 완제품 분류 자체는 유지해 부품 목록과 시세에 섞이지 않게 한다. 러너는 바꾸지 않았다(Worker 뒤에서만 호출된다).
- 검증: `npm test` 통과(`pc-local-projection` 계약은 두 값이 400인지 확인하도록 바꿈). 운영 페이지에 새 화면 파일을 끼워 선택지 2개, 묶음 전환(RTX 5090 101건→1건), 예전 완제품 링크의 단품 복귀, 앱 오류 없음을 확인했다.
- Worker `ec7436f3-0720-42a8-8bfd-1a4f3b8a2609`로 화면을 배포한 뒤 운영 API가 `ALL`·`COMPLETE_PC`에 여전히 200을 주는 것을 발견했다. 운영 Worker는 매물 요청을 검사 없이 러너로 넘기고, 고친 요청 검사는 로컬 서버 경로에서만 쓰였다. Worker 입구에서 공개 판매 구성 외 값을 400으로 막고 서비스 계약에 확인을 추가해 `e7e66a93-9142-407d-8e40-c8d34a88c7a7`로 배포했다.
- 운영 확인: API `ALL` 400, `COMPLETE_PC` 400, `SINGLE` 200, `BUNDLE` 200. 데스크탑·390px 화면 선택지 단품·묶음, 예전 완제품 링크는 단품(RTX 5090 101건)으로 열림, 패치 내역 항목·이미지 정상.
- 남은 점검 후보: 표본에서 CPU 쿨러가 CPU 묶음, 노트북 메인보드 부품이 완제품, 아이맥이 RAM 묶음, 단일 MSI 파워가 파워 묶음으로 분류된 사례가 보였다. 기본 단품 목록에는 영향이 없지만 정상 단품이 빠지는 경우가 있을 수 있다.

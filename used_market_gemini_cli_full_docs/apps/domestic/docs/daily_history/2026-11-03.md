# 2026-11-03 — 패치 내역·후원 페이지와 기록 방식

## 이유와 기준

Kstock의 패치 내역 페이지와 기능 완료 기록 방식을 USED PICK에도 적용해 달라는 요청이다. Kstock의 최신 공개 `/changelog`, `ChangelogPage.tsx`, 기능 전달 규칙과 2026-10-21·24 내부 변경 기록을 확인했다. Kstock은 읽기만 했으며 코드·운영 상태를 변경하지 않았다.

## 적용 범위

- `/changelog.html`: 최신 날짜부터 정렬한 짧은 제목을 누르면 실제 UI 이미지 한 장과 설명이 열린다. 이미지는 새 탭에서 원본 크기로 볼 수 있다. 가격·수치는 당시 화면이라는 안내를 유지한다.
- 확인된 2026-11-02 모바일 UI 배포를 관련 기능별로 묶고, 오늘 추가한 패치 내역·후원 페이지를 함께 기록했다. 실제 브라우저 화면 여섯 장을 공개 이미지로 사용한다.
- 기존 사이트의 PC 보조 메뉴와 세 모바일 메뉴, 사이트맵에서 두 페이지로 이동한다. 기존 문서 스타일을 재사용한 정적 HTML이며 날짜별 구분선과 기본 details로 구성했다.
- 추가 요청으로 `/support.html`을 함께 만들었다. Kstock의 공개 후원 페이지와 소스에서 확인한 IBK기업은행 계좌를 그대로 사용한다. 늘 적자로 운영 중이며 몇백 원의 작은 후원도 도움이 된다는 요청 문구와 서버비·사이트 운영 사용처를 짧게 안내한다. 결제·송금을 실행하거나 수취인 정보를 추정하지 않았다.
- 루트 AGENTS와 앱 README에 같은 작업에서 공개 패치 기록과 내부 일일 기록을 함께 갱신하는 규칙을 연결했다. 검증·배포는 기존 경로를 재사용한다.

## 검증과 배포

- 기존 UI 계약 23개와 HTML analytics 계약을 통과했다. 메뉴 연결, 사이트맵, 접근성 구조와 이미지 파일 참조를 기존 하네스에서 확인했다. 배포 경로의 Cloudflare 계약·dry-run·공개 건강 확인도 통과했다.
- Native IAB에서 390×844·320×568·1280×900을 확인했다. PC 링크와 두 모바일 메뉴 구현의 진입, 직접 새로고침, 키보드 Enter로 펼치기, 실제 PNG 로딩과 원본 이미지 새 탭 열기·닫기를 검증했다. 가로 넘침과 앱 오류가 없었다. 배치·날짜별 계층·작은 글자·흰 배경과 구분선·펼침과 원본 보기의 다섯 기준을 Kstock 실제 화면과 비교했다. USED PICK의 브랜드와 기존 탐색 구조를 유지했다.
- Kstock의 실제 공개 `https://kstockclock.com/support`와 USED PICK의 실제 공개 `/support.html`을 각각 읽어 은행과 계좌번호가 같은지 독립 대조했다. 작은 모바일 폭에서도 번호가 잘리지 않는다.
- 운영 기준 Worker `310fd62c-f730-494a-a177-35ab7fb4d2d2`를 직접 조회한 뒤 그 분리된 운영본에 정적 파일 18개만 반영했다. 배포는 한 번 실행했으며 실제 새 Worker는 `dee193fd-ec85-468e-b916-c8d2ae51b705`, 트래픽 100%다. 양 도메인의 18개 파일을 각각 대조했고 HTML은 기존 analytics 삽입 결과와 일치한다. 백엔드·가격 데이터·설정은 그대로 보존했다. 기존 릴리스의 실패 감지·이전 Worker 롤백 경로를 유지했다.
- 실제 공개 페이지의 메뉴 이동, 패치 이미지와 원본 보기, 후원 계좌를 다시 확인했다. 운영 화면 증거는 `C:/Users/tndud/.codex/visualizations/2026/11/01/01a197d8-8203-7181-abf6-d224994a0b81/changelog-production-mobile.png`, `support-production-mobile.jpg`, `support-production-desktop.png`다. 최종 후원 모바일 증거는 IAB getScreenshot으로 실제 화면을 저장했다. 배포 로그·범위·완료 영수증은 `.release-staging/changelog-20261103/`에 있다. 임시 뷰포트를 원복하고 후속 확인 예약을 제거했다.

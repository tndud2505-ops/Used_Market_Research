# 2026-11-03 — 패치 내역·후원 페이지와 기록 방식

## 이유와 기준

Kstock의 패치 내역 페이지와 기능 완료 기록 방식을 USED PICK에도 적용해 달라는 요청이다. Kstock의 최신 공개 `/changelog`, `ChangelogPage.tsx`, 기능 전달 규칙과 2026-10-21·24 내부 변경 기록을 확인했다. Kstock은 읽기만 했으며 코드·운영 상태를 변경하지 않았다.

## 적용 범위

- `/changelog.html`: 최신 날짜부터 정렬한 짧은 제목을 누르면 실제 UI 이미지 한 장과 설명이 열린다. 이미지는 새 탭에서 원본 크기로 볼 수 있다. 가격·수치는 당시 화면이라는 안내를 유지한다.
- 확인된 2026-11-02 모바일 UI 배포를 관련 기능별로 묶고, 오늘 추가한 패치 내역·후원 페이지를 함께 기록했다. 실제 브라우저 화면 여섯 장을 공개 이미지로 사용한다.
- 기존 사이트의 PC 보조 메뉴와 세 모바일 메뉴, 사이트맵에서 두 페이지로 이동한다. 기존 문서 스타일을 재사용한 정적 HTML이며 날짜별 구분선과 기본 details로 구성했다.
- 추가 요청으로 `/support.html`을 함께 만들었다. Kstock의 공개 후원 페이지와 소스에서 확인한 IBK기업은행 계좌를 그대로 사용한다. 늘 적자로 운영 중이며 몇백 원의 작은 후원도 도움이 된다는 요청 문구와 서버비·사이트 운영 사용처를 짧게 안내한다. 결제·송금을 실행하거나 수취인 정보를 추정하지 않았다.
- 루트 AGENTS와 앱 README에 같은 작업에서 공개 패치 기록과 내부 일일 기록을 함께 갱신하는 규칙을 연결했다. 검증·배포는 기존 경로를 재사용한다.

## 검증과 배포

- 기존 UI 계약 23개와 HTML analytics 계약을 통과했다. 메뉴 연결, 사이트맵, 접근성 구조와 이미지 파일 참조를 기존 하네스에서 확인했다. 배포 경로의 Cloudflare 계약·dry-run·공개 건강 확인도 통과했다.
- Native IAB에서 390×844·320×568·1280×900을 확인했다. PC 링크와 두 모바일 메뉴 구현의 진입, 직접 새로고침, 키보드 Enter로 펼치기, 실제 PNG 로딩과 원본 이미지 새 탭 열기·닫기를 검증했다. 가로 넘침과 앱 오류가 없었다. 배치·날짜별 계층·작은 글자·흰 배경과 구분선·펼침과 원본 보기의 다섯 기준을 Kstock 실제 화면과 비교했다. USED PICK의 브랜드와 기존 탐색 구조를 유지했다.
- Kstock의 실제 공개 `https://kstockclock.com/support`와 USED PICK의 실제 공개 `/support.html`을 각각 읽어 은행과 계좌번호가 같은지 독립 대조했다. 작은 모바일 폭에서도 번호가 잘리지 않는다.
- 운영 기준 Worker `310fd62c-f730-494a-a177-35ab7fb4d2d2`를 직접 조회한 뒤 그 분리된 운영본에 정적 파일 18개만 반영했다. 배포는 한 번 실행했으며 실제 새 Worker는 `dee193fd-ec85-468e-b916-c8d2ae51b705`, 트래픽 100%다. 양 도메인의 18개 파일을 각각 대조했고 HTML은 기존 analytics 삽입 결과와 일치한다. 백엔드·가격 데이터·설정은 그대로 보존했다. 기존 릴리스의 실패 감지·이전 Worker 롤백 경로를 유지했다.
- 실제 공개 페이지의 메뉴 이동, 패치 이미지와 원본 보기, 후원 계좌를 다시 확인했다. 운영 화면 증거는 `C:/Users/tndud/.codex/visualizations/2026/11/01/01a197d8-8203-7181-abf6-d224994a0b81/changelog-production-mobile.png`, `support-production-mobile.jpg`, `support-production-desktop.png`다. 최종 후원 모바일 증거는 IAB getScreenshot으로 실제 화면을 저장했다. 배포 로그·범위·완료 영수증은 `.release-staging/changelog-20261103/`에 있다. 임시 뷰포트를 원복하고 후속 확인 예약을 제거했다.

## eBay 환산 비교와 가격축 조절

- 이유: 전체 비교에서 eBay가 빠져 해외 가격과 비교할 수 없었고, 세로축이 보이는 구간 가격에 자동으로만 맞춰져 폭을 조절할 수 없었다.
- 환율: 유럽중앙은행 기준 USD→KRW 일별 환율을 Worker `/api/fx/usd-krw`가 키 없이 받아 6시간 캐시한다(`cloudflare/fx-rates.mjs`). 영업일만 있으므로 주말·휴일은 직전 영업일 환율을 쓴다. 과거 가격을 당일 환율 하나로 바꾸면 당시 원화 가격이 왜곡되므로 날짜별 환율을 사용한다.
- 화면: 전체 비교에 eBay를 별도 `eBay 환산` 선으로 추가했다. 배송비·부가세·관세가 빠진 표시가이므로 국내 평균에는 넣지 않는다. 차트 아래 오른쪽에 선택한 날짜의 환율을 회색 작은 글씨로 보여 주고 원·USD 전환을 둔다. USD에서는 국내 가격도 같은 날 환율로 바꾼다. "단위"와 "점선" 안내 줄을 없앴다.
- 가격축: 가격 눈금 영역을 위아래로 끌면 자동 범위를 중심으로 0.35~8배 넓히거나 좁히고, 축 더블클릭이나 전체 보기로 자동 범위로 돌아간다.
- 검증: `npm run test:pc`, pc-tools·UI·검색 미리보기 계약을 통과했다. 이번 코드로 운영 데이터를 로컬 브라우저에서 띄워 1280px·390px에서 eBay 환산 선, 주말 날짜의 직전 영업일 환율 표시, USD 전환, 가격축 끌기와 더블클릭 복귀, 앱 오류 없음을 확인했다.

## 오분류·판매 상태·상품 구성 교정 (준비, 운영 반영은 2026-11-04.md)

- 제보 링크를 공개 읽기 API로 재확인했다. i7-14700K의 eBay `287268659686`(US$21 BOX ONLY), RTX3060의 중고나라 `233105220`(ARC750 190,000원), Corsair 500W 이하의 TX401/TX201 랜카드 5건과 ACER 노트북 1건이 남아 있었다. 사용자 확인 당시 6건이던 랜카드는 이번 읽기에서는 5건이었다.
- RTX5090 중고나라 `232286629`는 LEGION Pro 7 완제품 7,450,000원, 같은 범위의 `226375407`는 호환용 수냉 블록이었다. RX580의 번개장터 `378201886`은 제목 `rx580 2048sp 8g (판매완료)`와 저장 상태 ACTIVE가 충돌했다. 원 사이트에서 실제 거래 완료를 확인한 것은 아니다.
- SSH의 기존 대상 신원을 확인하고 운영 SQLite를 `mode=ro`·`PRAGMA query_only=ON`으로 읽었다. 완료 게시본 `a718f370-5aec-433c-bd85-bbd02a793291`, 기준 `2026-11-02T18:01:03.049Z`, 정규화 19 / parser v8 / rules v19 / filter v7을 확인했다. 빈 상자·ARC750·TX401 대표 1건·LEGION의 해당 버전 및 30일 계산 범위에 통계적격 관측이 각각 4·16·1·20개 남아 있었다. 이는 관측 개수이며 고유 매물 표본 수나 가격 변화량이 아니다. 게시 가격에 대한 정확한 영향은 범위를 지정한 복구 미리보기에서 확인해야 한다.
- 분류: 영어 BOX ONLY/empty box와 부정 표현, ARC750의 A 생략 표기, TX201/TX401 네트워크 카드의 PSU 별칭 충돌, LEGION Pro/SLIM 및 구성 정보가 있는 노트북, GPU용 수냉 블록을 처리했다. 성능 비교의 `급`과 판매 의도의 `급처·급매`를 구분하고, A580/B580이 모두 있는 ARC580은 A 계열로 단정하지 않는다. 정상 부품·짧은 GPU 별칭·노트북에서 분리한 저장장치를 함께 검증했다.
- 저장된 ACTIVE가 제목의 전체 판매완료 근거를 덮지 않게 수정한다. 예약·삭제 등 명시적 상태와 부분 판매·부정 표현은 보존한다. 검색의 현재 판매중 총수·페이지를 계산하기 전에도 제목의 명시적 판매완료를 확인한다.
- 상품 구성: 기본 단품, 전체 구성·완제품·묶음을 서버에서 구분한다. 완제품 총액은 부품 통계에서 제외하고 부품 가격의 canonical ID를 부여하지 않는다. 모델 검색 연결은 별도의 검증된 구성 연관 정보로만 유지한다. 커서·총수·사이트별 수량은 같은 구성 필터를 사용한다.
- 기존 `9600` 문제는 현재 공개 `/api/pc/products`에서 재현되지 않았다. `9600`은 i5-9600K·i5-9600KF·Ryzen 5 9600X를, `9600K`는 i5-9600K만 반환했다. 검색 범위를 넓히는 불필요한 수정은 하지 않았다.
- 4개 제보 범위의 공개 매물 138건을 작업 시작 시 분류기와 비교했을 때, 확인된 교정 10건 외 128건의 모델·판매 구성·통계 적격 판정은 같았다. 결과와 원본은 Git에서 제외된 `tmp/nov3-fixes/`에 보존했다. 이 표본 비교는 전체 시장 정확도를 보장하지 않는다.
- 가격 선택창은 기존 가격 메타데이터를 모바일에서 숨기던 CSS만 보완했다. 503·390·1440px에서 운영 읽기 API를 연결한 로컬 화면을 확인했고, 기록 없음은 loopback 전용 응답으로 별도 검증했다. 표본 수·기준일·기록 없음 구분, 선택 동작, 가로 넘침과 앱 오류를 확인했다. UI restraint 스캐너의 반복 항목은 숨겨진 접근성 레이블·별도 대화상자 제목이 주로 차지했고, 실제 화면의 중복 로딩 문구 한 곳은 숨겼다.
- Browser 플러그인과 Aside 실행 경로가 없어 기존 Playwright 경로를 사용했다. 네이티브 Chrome 시작 실패 후 Edge로 검증했다. Chat On Steroids 실행 경로를 사용하지 않았으므로 해당 터널·companion 확인은 요구하지 않았다.

## 최종 정책

- 전체 페이지 수는 표시하되 내려받은 페이지와 바로 다음 페이지만 클릭할 수 있다.
- `다음`은 cursor 한 번으로 한 페이지만 요청한다.
- 수집 창을 넓히는 동작도 버튼 문구는 `다음`으로 통일한다.
- 사이트 보강 중에는 중복 확장을 막는다.
- 낮은 가격·높은 가격·최신 정렬은 SQLite 스냅샷에서 수행하며 원 사이트 정렬 재수집은 하지 않는다.

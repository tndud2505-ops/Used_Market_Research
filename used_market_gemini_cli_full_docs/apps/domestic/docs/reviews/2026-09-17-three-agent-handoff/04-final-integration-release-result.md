## 실제 통합한 내용

1번의 분할 게시 무결성·체크섬·이전 게시 범위 확인과 오류 진단, 2번의 최신 UI 수정, 3번의 가격 준비 상태·독립 검증 코드를 통합했다. 다만 Runner에서만 실행되는 수정 코드는 로컬 커밋에 포함됐어도 서버 교체 전이므로 운영 적용으로 계산하지 않는다. Worker에서 실행되는 게시 수신·검증 및 공개 API 코드는 이번 Worker 배포에 포함됐다.

이번 통합에서 `market/logic/pc-price-readiness.mjs`, `cloudflare/pc-price-response-guard.mjs` 및 경계 회귀 검사를 추가했다. 기존 Runner가 과거 미완성 집계를 HTTP 200으로 보내더라도 공개 Worker에서 이를 명시적 503/no-store로 변환한다. 원래의 불완전한 숫자와 현재 날짜의 요약을 과거 데이터처럼 전달하지 않는다. 기존 캐시의 잘못된 200 응답도 같은 검사를 거친다.

Runner에도 같은 순수 검사와 503/no-store 처리를 로컬 소스에 연결했지만 SSH 사전 조회가 차단돼 서버 파일을 바꾸지 않았다. 공개 보호 처리는 승인된 기존 Worker 경로에서 배포한 것으로 SSH 차단을 다른 서버 접근 경로로 우회한 것이 아니다.

최신 UI는 소수 단가×수량 표시, 필터만 초기화하고 저장 견적 유지, UNAVAILABLE/NO_EXACT_PUBLICATION 구분, 기간 불일치 검출, 모바일 카테고리 띠 CSS 수정이다. 모바일 CSS 파일이 배포됐다는 증거와 실제 화면 육안 검증은 구분한다.

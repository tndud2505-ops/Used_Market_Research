## 지스킬 운영 가격 누락 — 재현 완료, 근본 수정 미완료

매물 검색과 제품 선택용 카탈로그 검색은 다른 경로다. 제품 선택 API는 운영 상태에서 `G.Skill`로 27개, `gskill`·`G SKILL`·`지스킬`로 0개를 반환했다. 로컬 변경에서는 이 표기가 모두 27개로 일치한다. **아직 배포하지 않아 운영 응답은 바뀌지 않았다.**

지스킬 27개 가격 API는 모두 HTTP 200이었다. 12개 항목은 현재 또는 판매완료 표본이 있었지만, 6개 항목에서 화면 무결성 검사로 한 개 이상의 사이트가 제외됐다. HTTP 200만으로 가격 정상 반영을 판정하면 안 된다.

특히 `ram:g-skill:ddr5:16gb`의 번개장터 집계는 4건인데 중앙값이 null이었다. 프런트엔드가 이 사이트를 제외하면 다른 사이트 2건만 남아 대표가격을 표시할 수 없다. 검색어 변경만으로 해결되는 문제가 아니다.

원인 위치: `aws-runner/pc-parts-ledger.mjs`의 `storedDailyMetric`, `storedSummaryFromDailyRows`, `getStoredDailyPriceStats`. 여러 날짜의 통계를 합칠 때 중앙값을 보존하지 못하고, 일부 `average` 계산에 최솟값/중앙값을 대체 사용한다. `web-backend/public/pc-tools-core.mjs`의 `coherentStats`가 해당 사이트를 제외한다.

필요한 근본 수정은 격리된 게시 작업에서 계산한 정확한 전체/사이트별 통계 요약을 보존하고, 검증된 완전한 publication만 공개 읽기에 연결하는 것이다. 원시 매물 재집계를 공개 GET에서 수행하거나, 누락된 중앙값을 평균/최솟값으로 꾸며 넣어서는 안 된다. 통계 창·정규화 버전·승인 소스·통화·시장군·상태가 일치해야 하며, 과거 조회에는 현재 값을 대입하면 안 된다.

## 남은 완료 조건

1. 차단되어 적용되지 않은 통계 저장/조회 수정과 해당 재현 사례의 회귀 테스트를 완료한다. 정확 요약의 게시 원자성·보존 기간·정규화 버전·과거 조회를 검증한다.

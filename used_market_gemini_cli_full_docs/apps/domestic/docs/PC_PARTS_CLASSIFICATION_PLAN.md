# PC 부품 분류 개선 계획

## 목표

국내 전체·중고나라·번개장터·eBay가 같은 분류기를 사용하고, 사용자가 선택한 카테고리와 핵심 필터가 실제 매물 결과까지 일치하게 만든다.

통계 묶음은 유지한다.

- SSD·HDD: `제조사 × 용량 구간`
- 파워: `제조사 × 정격 출력 구간`
- RAM: `제조사 × DDR 세대 × 모듈 한 장 용량`
- 메인보드: 통계는 정확한 모델만 허용

세부 규격을 통계 ID에 넣어 표본을 잘게 나누지 않는다.

## 사용자 화면의 핵심 필터

| 카테고리 | 기본 필터 | 내부 판정만 유지할 값 |
| --- | --- | --- |
| 메인보드 | CPU 플랫폼, 소켓, 칩셋, 제조사 | 폼팩터, 메모리 세대, Wi-Fi 변형 |
| SSD | 제품 종류, 용량, 제조사 | PCIe 세대, M.2 크기, 프로토콜 |
| HDD | 내장·외장, 용량, 제조사 | 2.5·3.5형, SATA·SAS·USB, NAS·감시·기업용 |
| 파워 | 정격 출력, 크기 규격, 제조사 | 효율 등급, 모듈러 방식, ATX 세대 |

SSD 제품 종류는 `M.2 NVMe / 2.5형 SATA / M.2 SATA / 외장 / 기타·불명확`으로 판정한다.

## 우선순위와 완료 조건

### P0 — 잘못된 통계 차단

- 완제품 PC·노트북·미니PC가 CPU/GPU 단품 통계에 들어가지 않는다.
- `16GB 2장`, `[2개 일괄]`, `LOT OF 2`를 16GB 모듈 두 장으로 기록한다.
- 외장 저장장치와 서버·기업용 저장장치는 일반 데스크톱 기준 통계에서 제외한다.
- 통계에서 제외해도 저장장치 카테고리 매물 검색용 ID는 유지한다.

### P1 — 필터가 실제 매물까지 적용

- 화면에서 선택한 SSD 제품 종류, HDD 내장·외장, 파워 크기 규격을 매물 API에 전달한다.
- 수집 분류 → 로컬 검색 인덱스 → 내보내기 → D1 가져오기 → 공개 조회까지 값을 보존한다.
- 정확한 제품을 선택한 뒤에도 해당 핵심 필터를 함께 적용할 수 있다.

### P1 — 메인보드 0건 원인 분리

- 탐색 순서를 `CPU 플랫폼 → 소켓 → 칩셋 → 제조사 → 정확한 모델`로 통일한다.
- `AM5 + B650` 같은 선택에서 제품 수가 0으로 잘못 계산되지 않는다.
- `MSI MAG B650M MORTAR WIFI`, `B650M 박격포 WIFI`가 같은 정확한 모델 ID로 분류되는지 검증한다.
- 코드 판정이 성공하지만 운영 매물이 0이면, 다음 배포 때 기존 매물을 재분류하고 검색 인덱스·D1 공개본을 다시 만든다.

## 사이트별 확인표

| 사이트 | 확인할 오염 | 합격 기준 |
| --- | --- | --- |
| 중고나라 | 본체·일괄·장당·개당 표현 | 단품/묶음과 가격 범위가 함께 맞음 |
| 번개장터 | 옵션가·박스만·케이블만 | 본품이 아닌 매물은 통계 제외 |

| 국내 전체 | 사이트 간 중복과 통화 혼합 | 중복 제거 후 KRW 범위만 국내 통계에 사용 |

## 외부 에이전트용 실행 프롬프트

> 작업공간은 `C:\DeVelop\USED_WEB`이다. CPU·GPU·RAM·메인보드·SSD·HDD·파워 분류와 공개 매물 필터를 점검하라. SSD/HDD 통계 ID는 제조사×용량, 파워 통계 ID는 제조사×정격출력으로 유지하고 세부 규격으로 ID를 분할하지 마라. 완제품·외장 저장장치·서버/기업용 저장장치가 일반 데스크톱 통계에 섞이지 않게 하라. 메인보드는 플랫폼→소켓→칩셋→제조사 선택과 정확한 모델 분류가 같은 제품 집합을 가리켜야 한다. RAM의 `[2개 일괄]`, `LOT OF 2`, `16GB 2장` 수량과 총 용량을 검증하라. 중고나라·번개장터·eBay의 소스별 표현 차이를 기존 계약 테스트에 최소 사례로 추가하라. 라이브 마켓 호출, 자격증명 접근, 배포는 하지 말고 변경 파일·실행 테스트·남은 운영 절차를 보고하라.

## 배포 순서

1. 결정론적 테스트와 로컬 브라우저 검증
2. D1 `0014_pc_listing_facets.sql` 마이그레이션
3. 애플리케이션 배포
4. 운영자 승인 후 normalization/parser/rule 버전을 올리고 기존 매물 재분류
5. 검색 인덱스와 공개 D1 투영 재생성
6. 사이트별 대표 모델의 필터·통계 표본 확인

라이브 수집, 재분류, 배포는 운영자 작업이므로 자동 실행하지 않는다.

같은 normalization 버전은 이미 처리된 스냅샷을 건너뛰므로, 기존 행을 갱신할 때는 반드시 새 버전을 등록한 뒤 활성화한다.
